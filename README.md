# Random Codes Repository

This repository is, I think, a genuine attempt to engage with computation at a foundational level. Not in the sense of advancing the frontier — I want to be clear about that — but in the quieter, more personal sense of building real intuition through deliberate practice. There is something I find deeply compelling about that.

## Contents

- **44+ LeetCode problems in C++**, auto-synced via LeetSync. Arrays, trees, hashing, binary search, bit manipulation, greedy algorithms — the classics. I think working through these carefully, one at a time, is one of the more honest ways to understand how computers actually process information.
- **Hand-rolled data structures** — linked lists, stacks, queues, dynamic arrays, sorting algorithms. Implementing these from scratch is, I believe, one of the few reliable ways to stop taking them for granted.
- **A linear regression model in C++.** To be honest, this is not the obvious language choice for machine learning. But I think the friction is instructive. The discomfort is where the learning happens.
- **A UNIX shell, built from scratch.** Understanding the process model, I/O redirection, and command parsing at this level is one of those things that permanently changes how you think about operating systems. I'm proud of this one.

Feel free to explore and use anything you find useful here.
